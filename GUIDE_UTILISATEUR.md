## 1. ✨ Présentation du site

FoxTown Webmall est une application web de démonstration inspirée d'un centre commercial. Il permet de :

- 🛍️ Découvrir toutes les boutiques du centre commercial
- 🔍 Rechercher une enseigne par nom, catégorie ou étage
- 🗺️ Consulter le plan interactif du centre
- 🅿️ Vérifier les places de parking en temps réel
- 🎁 Jouer au jeu quotidien pour gagner des bons de réduction
- 👤 Gérer ses bons depuis un espace personnel

---

## 2. 👤 Créer un compte

La création de compte est **gratuite**. Elle est nécessaire pour jouer et consulter ses récompenses.

1. Cliquez sur **"S'inscrire"** en haut à droite
2. Renseignez votre **adresse e-mail**
3. Choisissez un **mot de passe**
4. Confirmez le mot de passe
5. Cliquez sur **"Créer mon compte"**

> Aucune information de paiement n'est demandée. Votre compte est créé avec le rôle visiteur standard.

---

## 3. 🔐 Se connecter / Se déconnecter

### Connexion

1. Cliquez sur **"Se connecter"** en haut à droite
2. Entrez votre **e-mail** et votre **mot de passe**
3. Cliquez sur **"Connexion"**

### Déconnexion

1. Cliquez sur votre nom ou icône de profil en haut à droite
2. Sélectionnez **"Se déconnecter"**

> Si vous utilisez un ordinateur partagé, pensez toujours à vous déconnecter.

---

## 4. 🛍️ Parcourir les boutiques

### Rechercher une boutique

- Utilisez la barre de recherche en haut de la page des boutiques
- Tapez quelques lettres du nom : les résultats s'affichent en temps réel

### Filtrer par catégorie ou étage

- Cliquez sur le menu **"Catégorie"** pour filtrer parmi 16 catégories (Mode femme, Sport & Équipement, Chaussures, Accessoires, Bijoux, Beauté, Restauration…)
- Cliquez sur le menu **"Étage"** pour n'afficher que les boutiques d'un étage précis
- Les deux filtres peuvent être combinés

### Voir le détail d'une boutique

Cliquez sur une boutique pour consulter :

- Nom et catégorie
- Étage
- Numéro de téléphone
- Horaires d'ouverture
- Lien vers le site officiel de la marque

### Ajouter une boutique en favori

- Cliquez sur l'icône **cœur** (♡) sur la page ou la liste d'une boutique
- Le cœur devient plein (♥) : la boutique est sauvegardée
- Cliquez à nouveau pour retirer le favori

> Les favoris sont sauvegardés dans votre navigateur — aucun compte nécessaire. Ils peuvent disparaître si vous videz les données de votre navigateur ou changez d'appareil.

---

## 5. 🗺️ Le plan du centre commercial

- Cliquez sur **"Plan"** dans le menu principal
- Le plan affiche la disposition des boutiques, espaces communs et sorties

> Consultez le plan avant votre visite pour organiser votre parcours.

---

## 6. 🅿️ Les parkings

- Cliquez sur **"Parking"** dans le menu principal
- Chaque parking affiche le **nombre de places disponibles en temps réel**

> Les données se mettent à jour automatiquement, aucune action nécessaire de votre part.

---

## 7. 🎁 Le jeu quotidien

> Un compte connecté est obligatoire pour jouer.

### Comment participer

1. Connectez-vous à votre compte
2. Cliquez sur **"Jeu"** dans le menu principal
3. Cliquez sur la carte pour la **gratter** et découvrir si vous avez gagné

### Règles

- **2 tentative par jour**
- Si la première tentative est **perdante** : une **2e chance** est accordée automatiquement
- Chaque tentative offre **30 % de chances de gagner**
- Maximum **10 gagnants par jour** sur l'ensemble du site — une fois le quota atteint, il n'est plus possible de gagner jusqu'au lendemain

> Jouez tôt dans la journée pour maximiser vos chances d'être parmi les 10 gagnants.

### En cas de victoire

- Un message de félicitations s'affiche
- Votre bon est ajouté automatiquement à votre compte
- Le code suit le format **FOX-XXXXXXXX**
- Retrouvez-le dans la section **"Mes récompenses"**

---

## 8. 🏆 Mes récompenses

1. Connectez-vous à votre compte
2. Cliquez sur votre profil puis **"Mes récompenses"**
3. La liste de tous vos bons s'affiche avec :
   - Le **code unique** (format FOX-XXXXXXXX)
   - La **date d'obtention**

Présentez votre code à la caisse de la boutique participante lors de votre achat.

> Vos codes restent accessibles ici tant que votre compte existe.
